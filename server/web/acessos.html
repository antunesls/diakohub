Pessoas

Cada pessoa entra no painel e no tablet com o próprio usuário e senha. Ela pode ter vários perfis e pode tudo o que qualquer um deles permite: quem é da Recepção e também ministra louvor recebe os dois. Como funciona

Perfis

O perfil é um conjunto de permissões. Dê a cada pessoa os perfis das funções que ela tem, em vez de criar um perfil para cada combinação. A mudança num perfil vale na hora para todos que o têm. O Administrador é travado, para ninguém perder o acesso. Como funciona
